# 阶段 3.2 消融实验报告

> 生成时间: 自动生成
> 基线: 30M seed2 @500步 (decay=-0.35%, 三链全开)
> 消融策略: 置零某链输出 (保持参数量 26.59M 不变, 严格控制变量)

## 实验设置

- **基线**: ThreeChainMamba2 30M (d_model=768, n_layers=2, seed=2, 500步)
- **消融方式**: 在残差融合前 `x = norm_fuse(x + x_s + x_t + c_inject)` 置零对应链输出
- **参数量**: 所有模型相同 26.59M (置零输出不删模块)
- **评估**: OOD T=150 (训练 T=100), 报告 changed_acc 的 t=100→150 decay

## 结果汇总

| 模型 | ablate_s | ablate_t | ablate_c | decay% | 窗口decay% | changed_acc@150 |
|------|----------|----------|----------|--------|-----------|----------------|
| Baseline (三链全开) | False | False | False | -0.35% | -0.22% | 0.5921 |
| 消融空间链 | True | False | False | -7.54% | -1.25% | 0.5491 |
| 消融时间链 | False | True | False | -0.38% | -0.62% | 0.5924 |
| 消融因果链 | False | False | True | -1.07% | -0.15% | 0.5876 |
| 三链全消融 | True | True | True | -0.66% | -0.51% | 0.5900 |

## 判定结论

- **消融空间链**: decay=-7.54% (单点), 窗口decay=-1.25% (±2%内), changed_acc@150 降 4.3% → 空间链**有实质贡献**（单点恶化显著, 窗口显示部分是 ch@100 噪声, 但 changed_acc 下降是实质性的）
- **消融时间链**: decay=-0.38% (±2%内) → 该链**非主因**
- **消融因果链**: decay=-1.07% (±2%内) → 该链**非主因**
- **三链全消融**: decay=-0.66% (±2%内), changed_acc@150=0.5900 (仅降 0.4%) → 不退化来自**AnchorInit2 初始表示 + 残差机制**, 三链演化是优化非必需

## 关键反常现象：单消融空间链恶化 > 全消融

| 模型 | decay% | changed_acc@150 | 与 baseline 差 |
|------|--------|-----------------|--------------|
| baseline | -0.35% | 0.5921 | - |
| no_spatial (单消融空间) | -7.54% | 0.5491 | **降 7.3%** |
| no_all (三链全消融) | -0.66% | 0.5900 | 降 0.4% |

**看似矛盾**: 单消融空间链恶化, 全消融反而不恶化。

**机制解读**:
1. **no_spatial 恶化原因**: 空间链被置零, 但时间链和因果链仍在工作。它们基于**残缺的 x**（缺少空间信息）继续演化, 导致错误信息被放大 → 预测质量下降。空间链的关键作用是**维持 x 的空间正确性**, 供其他链基于正确输入演化。

2. **no_all 不恶化原因**: 三链全置零, `x = norm_fuse(x + 0 + 0 + 0) = norm_fuse(x)`, 只剩 AnchorInit2 初始表示 + 残差。模型靠 `cell_embed(S_0) + act_mean + time_emb` 初始锚定直接预测, 这已足够。三链演化是"锦上添花"的优化, 非长程预测的必需。

3. **changed_acc@150 印证**: no_all=0.5900 (接近 baseline 0.5921), 说明 AnchorInit2 初始表示已能预测变化 cell; no_spatial=0.5491 (明显更低), 说明残缺输入误导了其他链。

## 机制修正：从 3.1 到 3.2

3.1 探针发现（看三链 norm 稳定性）:
- H1 支持: 时间链 h_t 在 OOD 区稳定
- H2 推翻: 空间链 h_s 未显著衰减
- H3 支持: 因果链 h_c 极其稳定
- 核心结论: 不退化来自**架构整体稳定性** (三链并行 + 残差融合), 而非单链独撑

3.2 消融实验**修正**了 3.1 的解读:
- 空间链虽自身 norm 稳定 (3.1 H2), 但消融后其他链因输入残缺而恶化 → 空间链的作用是**维持信息正确性**而非直接承载长程
- 时间链/因果链消融无影响 → 这两链对长程外推**非必需**
- 全消融不退化 → **不退化的根本原因是 AnchorInit2 初始表示的完整性** (cell + action + time 三源锚定), 三链演化是性能优化层

**最终机制结论**: 不退化来自**双层次保障**:
1. **基础层** (必需): AnchorInit2 初始表示 + 残差连接 + LayerNorm → 即使三链全消融仍稳定
2. **优化层** (锦上添花): 三链演化提升精度, 其中空间链对维持信息正确性最关键 (单消融即恶化)

## 判定标准

- 消融某单链后 |decay| > 2% → 该链**贡献**不退化
- 消融某单链后 decay 仍 ±2% → 该链**非主因**
- no_all decay <-6% → 三链**协同**贡献
- no_all decay 仍 ±2% → 不退化来自**残差融合机制本身**
